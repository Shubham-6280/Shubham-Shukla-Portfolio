## 🚀 Running Locally

```bash
# 1. Navigate to portfolio folder
cd portfolio

# 2. Install dependencies (already done)
npm install

# 3. Start development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

---

## 📦 Building for Production

```bash
cd portfolio
npm run build
```

The production output is generated in `portfolio/dist`.

---

## 🌐 Deploying to Vercel

### Option 1: Vercel CLI (Fastest)
```bash
cd portfolio
npx vercel
```

### Option 2: GitHub & Vercel Dashboard
1. Push this folder to a GitHub repository (e.g. `Shubham-6280/portfolio`).
2. Go to [https://vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository.
4. Set **Root Directory** to `portfolio` (or root if the repository contains only this portfolio).
5. Framework Preset: **Vite**.
6. Click **Deploy**!
